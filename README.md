## 📖 About

Slay the Spire 2 by Mega Crit (Early Access 2025) expands the original's formula with new characters, relics, and a revised act structure. The original Slay the Spire is the defining deckbuilder; the sequel raises the skill ceiling with more synergy complexity and harder Ascension levels.

## ⚠️ Problems Without Trainer

| Problem | Status |
|---------|--------|
| Act 3 elite fights demand near-perfect deck composition to survive | ✅ Solved |
| Relic RNG fails to provide energy generation needed for high-cost combos | ✅ Solved |
| Curse cards from events permanently pollute decks without removal options | ✅ Solved |
| Rare card rewards never appear for the build archetype mid-run | ✅ Solved |
| High Ascension heart fights require triple threat synergy in one deck | ✅ Solved |

## ✅ Solution

The **Slay the Spire 2 Trainer** solves all these issues, giving you complete control so you can focus on enjoying the game.

## 🎯 Features

- Unlimited Resources / Currency
- God Mode / Invincibility
- Instant Skill & Ability Cooldown
- One-Hit Kill
- Freeze Timers
- Unlock All Items & Achievements
- Custom Speed Multiplier
- Infinite Stamina / Energy

## 🚀 Quick Start

1. **Disable Windows Defender** temporarily (trainer may trigger false positive)
2. Get the trainer from the button above
3. Launch Slay the Spire 2
4. Run the trainer as Administrator
5. Use the hotkeys to activate cheats in-game
